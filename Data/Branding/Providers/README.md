# Provider Icons

OpenAI, Claude and Gemini vector silhouettes from [LobeHub Icons](https://github.com/lobehub/lobe-icons/tree/8b7bbc433d38437fa2b0cca58ae896917162b812), commit `8b7bbc433d38437fa2b0cca58ae896917162b812`, under the included MIT license. Logos identify the selected provider; provider names and marks belong to their respective owners.

Source files are preserved here. `scripts/build-provider-icons.py` renders flat theme-colored ICOs using system librsvg and Cairo as build-only tools (no Python packages). No icon package or SVG renderer is required at runtime.
