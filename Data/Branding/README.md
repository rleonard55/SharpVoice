# SharpVoice microphone artwork

User-supplied faceted microphone design, prepared with the built-in image-generation tool (not the API/CLI fallback). `microphone-states.png` is the selected RGBA sheet: silver/neutral, red/recording, amber/error or warning. One later cleanup variant was not selected. The tool's original outputs remain in its generated-images directory.

Run `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-brand-icons.ps1` from the repository to package it. Packaging preserves the generated alpha, extracts the three states, uses a common scale/baseline and creates 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixel ICO frames. PNG previews are saved beside the ICOs in `src/SharpVoice.UI/Assets`. The script renders previews over light and dark backgrounds in `.build-cache/branded-icons-preview.png`. No background-removal filter runs during packaging. The sound generator no longer overwrites branded icons.

The neutral ICO is also the executable's ApplicationIcon; the existing runtime feedback state applies matching small/large icons to the tray, Settings and HUD windows. Recording is red, errors/warnings are amber, and idle/processing is silver.

## Final selected edit prompt

Edit the user's attached image of three SharpVoice microphone logos. Remove the solid black background completely and output TRUE RGBA transparency, including all the gaps between mic supports and bodies and the diagonal slash-shaped negative spaces within each microphone. Preserve the three exact angular, faceted microphone designs and their metallic silver, vivid red, and amber/yellow-orange colors, in that same left-to-right order. They are three states of the SAME app icon, so preserve exactly matching silhouette, scale, alignment and baseline. Output a clean horizontal row of three icons, each centered in its own equally sized square cell, with transparent padding and transparent gaps so the three equal cells can be extracted for app icon files. Keep the microphone large within each cell (roughly 85% cell height). Preserve sharp beveled highlights and rich color gradients from the reference. Remove black shadows/background haze and oversized glow; any tiny edge glow should have alpha transparency, never dark baked-in halos. No text, borders, opaque square backgrounds or extra symbols. This is a faithful transparent cutout of the supplied design, not a redesigned logo.
