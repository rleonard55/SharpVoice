# Windows prototype smoke test

## Optional Wake Phrases

- Confirm a new/legacy configuration stays On Hotkey with wake activation Off and no idle microphone use.
- Open Audio → Wake Phrases, enable it and save. Verify the listener uses the currently selected Whisper model, with local speech activity gating and a truthful Listening/Paused/Unavailable state. Any missing Whisper/speech-activity asset prepares automatically with cancellation/retry; no keyword archive is requested. Change Whisper model while idle and verify wake detection restarts with that selection. During silence, diagnostic Whisper checks should stay at zero; speech checks increase the count.
- In Notepad with AI cleanup Off, say “Hey SharpVoice Dictate, please bring the blue folder tomorrow” continuously. Verify the start cue, live draft when enabled, stop after two seconds of silence, and insertion of only the request text. Ask AI must not reject this as an unconfigured provider.
- With a configured provider, say “Hey SharpVoice, what is the capital of Texas?” Verify normal Ask AI behavior; the wake prefix must not appear in the request. Say only the phrase, then stop; verify no AI call or inserted placeholder. A [BLANK_AUDIO] transcript must produce no text.
- Test a quiet voice and background room/TV noise; adjust the microphone noise gate and choose distinctive phrases if needed. Check for clipped first words and false activations. Repeat both phrases with no pause before the request.
- Pause from the tray and verify Windows releases microphone capture. Resume and verify wake listening recovers. While an answer is read aloud, verify the microphone is suspended and playback cannot start another request.
- Stop a wake recording using its matching hotkey; its release must not start/stop another session. Escape cancels. Check normal Hold and Toggle hotkey recordings still work with wake activation enabled and disabled.
- With a permissive gate (for example −71 dB) and steady room noise above it, repeat both wake modes at least six times. Verify speech-end detection still stops each request, inserts only once and rearms. Try a continuous request longer than 40 seconds, quiet speech, pauses shorter than the selected silence duration, and readout followed by a new request. Local speech detection must not alter the configured transcription gate.
- During recording, processing, an editor voice session or a pending code preview, verify unrelated wake detections cannot create another operation or bypass a diff/approval. Change microphones while idle and verify old-device detections cannot activate the replacement.
- Disable wake phrases and restart SharpVoice. Confirm the preference is recalled, and On Hotkey releases idle capture unless an explicit Audio preview is active.

Run from a normal Windows desktop session. Do not run elevated unless the target app also requires elevation. These checks exercise native behavior that a Linux build cannot prove.
