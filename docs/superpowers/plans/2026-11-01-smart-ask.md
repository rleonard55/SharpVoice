# Smart Ask Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Track checkbox tasks and rulings here.

**Goal:** Optional intent-aware Ask AI with a readable response pill and Edge/Windows speech.
**Architecture:** Core result contracts/settings, one-call refiner routing, cancellable Windows speech service and separate native response UI, integrated by the app.
**Tech Stack:** .NET 10 Native AOT, native Win32/SAPI/MCI, optional external edge-tts.
**Spec:** docs/superpowers/specs/2026-11-01-smart-ask-design.md

## Global Constraints
- Off by default; remember preferences; preserve dictation and explicit editor preview paths.
- Never automatically paste answer-route text or malformed envelopes.
- No live user accounts, microphone, clipboard, editors or audible output in tests.
- No new paid API, automatic helper installation, plaintext speech files or source text in process arguments.
