# SharpVoice 0.1.10

This release simplifies Audio Settings and fixes completed Ask AI answers being rejected in the IDE plugin.

- A compact input card combines the live microphone level and draggable noise gate on one scale. Sound above the gate turns green.
- Enter an exact dB value, including decimals, or adjust the gate with the mouse or arrow keys. The Live Transcript switch sits beside the gate field, freeing more space for Last Result.
- The control supports both themes, native keyboard interaction and checked-state accessibility. Preferences take effect with Apply Settings.
- Plugin Ask AI now displays completed plain-text and fenced answers, including ChatGPT replies previously rejected with “The AI did not return a complete structured answer.” Structured follow-up questions and quick replies retain strict validation; incomplete or interrupted responses remain rejected.

Includes the unchanged IDE plugin **0.3.3 / editor protocol 9**. No plugin reinstall is needed if you already have 0.3.3. For older versions, use **Settings → General → Plugins**, update/reinstall and reload the editor. Antigravity compatibility remains experimental.

Preferences, protected credentials, downloaded models and update policy are preserved. Includes Whisper Tiny Q5 English in the installer, portable ZIP and full update package. Windows 10/11 x64 with AVX2/FMA required. Packages remain unsigned. Restart clears memory-only conversations.
