# SharpVoice 0.1.9

This release fixes resident memory staying elevated after pressing and releasing a recording hotkey without speaking.

- Idle cleanup now covers silent recordings and canceled capture, in both Keep Ready and On Hotkey microphone modes.
- Cleanup runs after two quiet seconds, once model preload, live transcription and active work have drained. It runs once per operation and does not trim during recording.
- The speech model remains cached for reuse. Working-set trimming releases resident RAM pages; it does not immediately free all committed model allocations.
- Release checks now exercise silent hotkeys, cancellation and repeated recording with synthetic audio and the verified bundled Tiny model in both microphone modes.

The preceding one-click Install and Restart flow is included. Preferences, protected credentials, downloaded models and update policy are preserved.

Includes the unchanged IDE plugin **0.3.3 / editor protocol 9**. No plugin reinstall is needed if you already have 0.3.3. For older plugin versions, use **Settings → General → Plugins**, update/reinstall and reload the editor. The VSIX is also available below; Antigravity compatibility remains experimental.

Includes Whisper Tiny Q5 English in the installer, portable ZIP and full update package. Windows 10/11 x64 with AVX2/FMA required. Packages remain unsigned. Restart clears memory-only conversations.
