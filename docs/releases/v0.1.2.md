# SharpVoice 0.1.2

The recording pill now raises above other application windows each time recording starts or a status explicitly displays it, while keeping keyboard focus in the original text field. Its click-through behavior, size, position and normal dismissal are preserved.

Includes Whisper Tiny Q5 English in the default installer, portable ZIP and full update package, as in 0.1.1. Saved preferences and the existing update/restart policy are preserved. Windows 10/11 x64 with AVX2/FMA required; this release remains unsigned.
