# SharpVoice 0.1.4

- New users automatically get a skippable first-launch setup wizard for microphone testing, shortcuts, optional AI, and local practice dictation. Practice text stays inside setup. Existing profiles retain tray startup; setup is not available from the General tab.
- General Instructions starts pre-filled with the built-in cleanup instructions on fresh installs. Existing saved instructions, including an intentionally empty field, are preserved. The prompt is compiled into the app, with no separate TXT file required.
- The editable cleanup template is sent once for dictation cleanup and stays separate from selection and code-edit instructions.
- The recording pill follows the focused app's monitor while preserving its relative placement.

Includes Whisper Tiny Q5 English in the installer, portable ZIP, and full update package. Existing preferences and update policy are preserved. Windows 10/11 x64 with AVX2/FMA required; this release remains unsigned.
