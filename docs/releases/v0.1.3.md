# SharpVoice 0.1.3

- The recording pill is more transparent (85% opacity).
- Successful paste confirmation dismisses after about 0.9 seconds. Errors and other outcomes remain visible longer.
- Drag the pill anywhere to move it without taking typing focus. Its position is saved for future launches and kept on an available monitor. Dismissal and automatic update installation pause during dragging.

Includes Whisper Tiny Q5 English in the default installer, portable ZIP and full update package. Existing preferences and update policy are preserved. Windows 10/11 x64 with AVX2/FMA required; this release remains unsigned.

Automated checks cover native window behavior and synthetic drag events on an isolated desktop. Physical mouse dragging remains a manual smoke check.
