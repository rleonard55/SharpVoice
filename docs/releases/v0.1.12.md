# SharpVoice 0.1.12

Fixes an application freeze that could occur while wake phrase listening was enabled and leave hotkeys and the interface unresponsive.

- Removes a lock conflict between microphone capture and the interface's idle checks. Wake listening, dictation and update eligibility retain their existing behavior.
- Adds a regression test that reproduces the conflicting timing and verifies that microphone processing and idle checks both finish, with wake listening enabled and disabled.

Includes IDE plugin **0.3.4 / editor protocol 9**. Preferences, protected credentials, downloaded models and update policy are preserved. Includes Whisper Tiny Q5 English in the installer, portable ZIP and full update package.

Windows 10/11 x64 with AVX2/FMA required. Packages remain unsigned. Restart clears memory-only conversations.
