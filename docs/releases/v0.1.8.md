# SharpVoice 0.1.8

Install and Restart now handles the complete update flow in one click.

- The button is available in supported release installations before checking for or downloading an update.
- It checks when needed, downloads and verifies the update, then installs and restarts. An already verified download is reused, including while offline.
- If dictation, AI work, spoken answers or wake recognition is active when the download finishes, the explicit restart request waits for that work to finish.
- No newer release, download failures, failed verification and canceled operations leave the app open. Update operations disable repeated clicks.
- Manual installation remains available when Automatic Updates is Off. Automatic update preferences and restart policy remain independent.

Restart clears memory-only conversations. Preferences, protected credentials and downloaded models are preserved.

Includes the unchanged IDE plugin **0.3.3 / editor protocol 9**. No plugin reinstall is needed if you already installed 0.3.3 with SharpVoice 0.1.7. For older plugin versions, use **Settings → General → Plugins**, update/reinstall and reload the editor. The VSIX is available below for manual installation; Antigravity compatibility remains experimental.

Includes Whisper Tiny Q5 English in the installer, portable ZIP and full update package. Windows 10/11 x64 with AVX2/FMA required. Packages remain unsigned.
