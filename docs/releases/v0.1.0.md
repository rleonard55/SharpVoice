# SharpVoice 0.1.0

First Windows x64 release: local Whisper dictation, optional AI cleanup and Ask AI, voice-driven editor previews, wake phrases, in-memory conversations and connected tools with visual approval.

- Per-user installer and portable ZIP; no administrator rights or separate .NET runtime required.
- Transparent microphone branding, OS light/dark settings, and model downloads managed by the app.
- GitHub release updates under **Settings → General → Updates**. Automatic Updates is independent from the Notify Only / Download Automatically / Install When Idle action. Defaults: On and Install When Idle.
- Automatic installation waits for at least 60 quiet seconds, closed settings/review windows and no active voice, AI, authentication or speech work. Restart clears memory-only conversations. Manual check/download/install controls are always available.
- User preferences, credentials and downloaded models stay outside the installation and are preserved by upgrades and uninstalling.

This release is unsigned; Windows may show an unknown-publisher or SmartScreen prompt. Wake phrases and editor/provider integrations should be treated as early features while broader Windows testing continues.

Updates require this repository and a published release to be public. Draft/private releases are not visible to the public updater; account credentials are never bundled for update access.
