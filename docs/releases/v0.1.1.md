# SharpVoice 0.1.1

The default Windows installer, portable ZIP and update package now include **Whisper Tiny Q5 English**. New users can dictate without a separate model download or AI account.

- The included model is verified against its pinned SHA-256 before use. Existing valid cached models take priority; choosing another model retains on-demand downloads. Saved preferences are preserved.
- Includes the MIT license for SharpVoice and the OpenAI Whisper model notice, alongside existing third-party notices.
- Clarifies that the default cleanup prompt is built in; General Instructions adds optional preferences.

Windows 10/11 x64 with AVX2/FMA required. This release remains unsigned. Cloud AI and online speech require their respective connections. Wake phrases prepare their separate speech-end detector when enabled. Installer updates retain the existing idle/restart policy; restarting clears memory-only conversations.
