# SharpVoice 0.1.5

- AI & Models now includes **Diagnostics** with useful explanations for ChatGPT and Gemini API connection, TLS, proxy, HTTP, timeout and interrupted-response failures.
- Diagnostics identify whether sign-in/token refresh, model discovery or inference failed. Request deadlines cover response streaming, and nested failures are recorded once.
- Preview and explicitly copy a sanitized report containing up to 20 recent failures. Records stay in session memory and can be cleared; no automatic diagnostic uploads occur.
- Open a GitHub issue form from Diagnostics, then paste, review and submit the report yourself. Report data is never included in the browser URL, and SharpVoice stores no GitHub credentials. Public issues are public and linked to the reporter's GitHub account; the same report can be shared privately with IT.
- Reports exclude dictated text, prompts, responses, credentials, internal hostnames, certificate identities and raw logs. Known provider output limits retain actionable guidance; unexpected HTML responses are distinguished from interrupted streams.

Includes Whisper Tiny Q5 English in the installer, portable ZIP and full update package. Existing preferences, credentials and update policy are preserved. Windows 10/11 x64 with AVX2/FMA required; this release remains unsigned.

Known minor limitation: the latest explanation and report are sampled separately, so a concurrent failure can make the explanation newer than the preview. Copy Report always copies exactly the displayed report.
