# SharpVoice 0.1.7

This release adds the Blue + Indigo visual refresh to the desktop app and IDE plugin, including the complete gradient and curved-wave Settings header.

- Dark and light desktop themes use coordinated navy and pale-blue surfaces, azure actions and colored tab icons.
- The Settings header now renders its blue-to-indigo gradient and curved wave accents continuously behind the title and tagline.
- Healthy microphone activity uses green meter and monitoring indicators.
- The IDE panel adds an indigo gradient header and clearer colors for follow-up questions, accepted changes and recording. High-contrast editor themes retain their native color tokens.
- Theme contrast checks and native header rendering checks cover dark and light themes, including switching between them.

## Update the app and plugin together

Includes IDE plugin **0.3.3 / editor protocol 9**. After updating SharpVoice, open **Settings → General → Plugins**, update/reinstall the plugin for each editor, and reload that editor. The VSIX is also available below for manual installation. VS Code and Insiders use the shared package; Antigravity compatibility remains experimental.

Includes Whisper Tiny Q5 English in the installer, portable ZIP and full update package. Existing preferences, protected credentials and update policy are preserved.

Windows 10/11 x64 with AVX2/FMA required. Packages remain unsigned.
