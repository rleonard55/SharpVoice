# SharpVoice 0.1.6

This release brings working-file change review and contextual Ask AI to the IDE plugin, with faster voice shortcuts and clearer follow-up questions.

- AI code changes appear directly in the working file. Continue making requests, edit or test the result, then accept or revert individual changes, the current file, or all pending files. An optional cumulative diff, native Undo and local review recovery support longer sessions.
- The configured Dictation and Ask AI shortcuts route through the focused IDE and respect Hold/Toggle preferences. Ask AI stays read-only and automatically includes the current filename, extension, language and highlighted text. Include Current File adds bounded file content; without a selection it sends file details only unless that option is enabled.
- Document, Comment, Uncomment, Explain and Format shortcuts use the current selection where appropriate. Comment/Uncomment require an initial selection and use native language-aware commands. Invalid language operations, including comments in strict JSON, are rejected before writing.
- Follow-up questions in Ask AI and code edits are highlighted, play a distinct sound and offer suggested reply buttons when available, alongside voice and typed replies.
- New IDE tools include diagnostic Fix/Explain Error, symbol navigation, Test This, existing test-task selection, related-file context and coordinated edits, custom shortcuts, read-only Explain Changes and bounded project conventions.
- Audio Settings automatically monitors the applied microphone while visible and idle, replacing Preview Applied Mic. Monitoring is local with no transcription; leaving Audio, hiding/minimizing Settings, recording, answer playback or pausing suspends it.
- Smart Ask AI now has separate Read Answers Aloud and response-length preferences, with improved answer dismissal and cancellation behavior.

## Update the app and plugin together

Includes IDE plugin **0.3.2 / editor protocol 9**. After updating SharpVoice, open **Settings → General → Plugins**, update/reinstall the plugin for each editor, and reload that editor. The VSIX is also available below for manual installation. VS Code and Insiders use the shared package; Antigravity compatibility remains experimental.

Includes Whisper Tiny Q5 English in the installer, portable ZIP and full update package. Existing preferences, protected credentials and update policy are preserved. Contextual Ask conversations are scoped to the file; conversation transcripts remain in memory. Review recovery stores bounded pending source/baselines locally in the IDE workspace.

Windows 10/11 x64 with AVX2/FMA required. Packages remain unsigned. Working-file edits can be saved by the editor's Auto Save setting; review controls are separate from saving.
