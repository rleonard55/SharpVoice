# SharpVoice 0.1.11

This release brings the refreshed Indigo design into the Windows app and setup wizard, and keeps installed IDE plugins updated with SharpVoice.

- Settings and setup share lighter surfaces, compact branding, colored navigation icons, card outlines and consistent button styling in both Windows themes. Existing provider icons remain in the AI selector.
- The four-step setup wizard includes a visible progress indicator, explicit microphone testing, optional AI setup and isolated dictation practice. Clear Text is available after practice; recording blocks conflicting actions. An unavailable saved microphone prompts you to choose another or skip setup.
- Updates opens with Check Now as the primary action. Download and Install And Restart require an available update. Install And Restart downloads and verifies the update when needed, then waits for active work to finish.
- Existing SharpVoice plugins in VS Code, VS Code Insiders and Antigravity update automatically after an app/bundled-plugin version change. Newer plugin versions are preserved, missing plugins are left alone, and failures retry on the next launch. Reload open editors to activate an updated plugin.
- IDE hotkeys can fall back to ordinary desktop dictation when no suitable editor document is focused. Ask AI retains document context when the plugin accepts the request. Cancellation and contextual settings controls are more consistent.

Includes IDE plugin **0.3.4 / editor protocol 9**. First-time plugin installation remains available in **Settings → General → Plugins**. Antigravity compatibility remains experimental.

Preferences, protected credentials, downloaded models and update policy are preserved. Includes Whisper Tiny Q5 English in the installer, portable ZIP and full update package. Windows 10/11 x64 with AVX2/FMA required. Packages remain unsigned. Restart clears memory-only conversations.
