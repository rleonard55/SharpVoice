# README screenshots

Captured from SharpVoice’s actual native UI on 2026-11-02. Settings and the answer popup were rendered on an isolated Windows desktop; the pill was rendered offscreen with the production Direct2D renderer. BMP captures were encoded as PNG without retouching.

All text is synthetic demonstration content. No microphone, provider request, personal configuration, account information or private conversation was used. Settings show the default Tiny Q5 model, Standard processing and AI refinement off. “Sample Answer” identifies supplied demo content, not a provider/model claim.
